# Can an LLM Run an NPC?

NC State CSC 484/584 guest talk: language models running NPCs, the cost of deploying them, and agents used for game playtesting.

Open it at https://sgilson7.github.io/game-ai-agents-deck/. Arrow keys move between slides; N shows the speaker notes; each animation has Play, Pause, Step and a text list of its steps. Every slide credits its sources, and the last slide lists them all.

Sam Gilson, Game2Learn lab, NC State. Guest lecture for Dr. Tiffany Barnes's CSC 484/584 Game AI, 19 November 2026.
